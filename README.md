## Hướng dẫn chạy game
1. Mở thư mục `gamedangcaptop1vietnam`.
2. Chạy file `.exe`.

## Xem source code
- **Phiên bản Unity:** Dùng bản Unity mới nhất (hoặc bản 2022 trở lên) là mở được project.
- Add thư mục này vào Unity Hub để mở.
- Toàn bộ source code (các class, logic game, thuật toán bot...) em đặt tập trung trong thư mục `Assets/Scripts`.
